La pregunta del caso

¿Abstracto o concreto?

Cuando la Suprema Corte protege derechos humanos, ¿argumenta distinto si revisa una ley "en el papel" (acción de inconstitucionalidad) que si resuelve el caso de una persona (amparo)?

Tres hipótesis para discutir

H1 En la vía abstracta, más test de proporcionalidad.

H2 En la vía concreta, más fuentes internacionales.

H3 La perspectiva de género aparece igual en ambas.
