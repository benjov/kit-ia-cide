Instalar el skill del caso

  1. Comprime la carpeta skills/codificador-scjn en un .zip (clic derecho → Comprimir).
  2. Claude Desktop → Configuración → Capacidades: activa la ejecución de código y creación de archivos.
  3. En la sección Skills, sube el .zip y actívalo.
  4. Prueba en Cowork: "Usa el skill codificador-scjn para codificar 2 documentos de ejercicio/muestra-20."
